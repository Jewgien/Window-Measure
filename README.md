# Window-Measure
Разработка прототипа мобильного приложения для определения размеров прямоугольных оконных и дверных проёмов по фотографии. Для вычисления масштаба рядом с проёмом размещается объект известного размера, например лист А4, линейка или специальная метка

## Этапы проектирования

### Этап 1. Разобраться в задаче, понять ожидаемый результат и определить первые шаги
-  Составлен список вопросов — [docs/stage-1.md](docs/stage-1.md)
-  Сформирован основной пользовательский сценарий — [docs/stage-1.md](docs/stage-1.md)
-  Обсуждена минимально рабочая версия — [docs/stage-1.md](docs/stage-1.md)

### Этап 2. Техническая основа проекта
-  Проект создан, код лежит в Git-репозитории
-  Проект запускается на компьютере (`START_WINDOWS.bat`)
-  Сборка APK для Android (`buildozer.spec` готов, APK пока не собран)
-  Главный экран и экран «Новый замер» — `main.py`, `new_measurement()`, скриншот `docs/screen_home.png`
-  Переходы между экранами — `ScreenManager` в `main.py`

### Этап 3. Получение изображения с камеры или из памяти устройства
-  Актуальная версия на Git, приложение запускается
-  Съёмка с камеры реализована в коде — `oknomer/platform_io.py` (на телефоне ещё не проверена)
-  Выбор фото из галереи/файлов — `windows_dialog.py` (ПК), `platform_io.py` (Android, на телефоне не проверен)
-  Фотографии отображаются в приложении — `PhotoCanvas` в `main.py`

### Этап 4. Границы измеряемого проёма на фотографии
-  Поверх изображения ставятся точки — `PhotoCanvas.on_touch_down`
-  Точки образуют контур
-  Точки можно перемещать — `PhotoCanvas.on_touch_move`
-  Разметку можно сбросить — кнопка «Сбросить», `reset_points()`
-  Все изменения на Git, приложение запускается — скриншот `docs/screen_markup.png`
