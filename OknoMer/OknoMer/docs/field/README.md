# Формат натурных измерений

Серия сопоставляет ширину и высоту одного и того же контура на фотографии и по рулетке. Для каждого кадра журнал хранит объект, эталон, ракурс, условия, способ разметки, контрольные и вычисленные размеры в миллиметрах. Для отклонённого кадра сохраняется причина отказа. [Структура CSV](trials-template.csv).

## Обработка

```powershell
py -3 tools/field_report.py prepare window.zip --out trials.csv
py -3 tools/field_report.py report trials.csv --out field-results
```

Первая команда переносит замеры из экспорта приложения. Вторая обрабатывает таблицу с внесёнными контрольными размерами. Погрешность рассчитывается отдельно для ширины и высоты. В опубликованной серии использованы контрольные изображения с известной геометрией. Натурные наблюдения отсутствуют.
